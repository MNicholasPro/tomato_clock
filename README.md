# 专业番茄时钟

一个基于 Electron 构建的现代番茄时钟应用，帮助你高效管理时间。

## 功能特性

- ✨ 简洁美观的毛玻璃设计
- ⏱️ 可自定义的专注和休息时间
- 🔔 滴答声和完成音效提醒
- 🎨 平滑的背景过渡效果
- 📱 响应式设计，支持不同屏幕尺寸
- ⏯️ 完整的播放/暂停/重置控制
- 📦 可打包为独立应用，方便分发

## 快速开始

### 安装依赖

```bash
npm install
```

### 运行应用

```bash
npm start
```

## 使用说明

### 基本操作

1. **开始专注**：点击"开始"按钮开始计时
2. **暂停计时**：点击"暂停"按钮暂停当前计时
3. **重置计时**：点击"重置"按钮重新开始
4. **切换模式**：点击底部的"休息一下"或"回到专注"按钮在专注和休息模式间切换

### 自定义设置

- **设定时间**：在侧边栏输入框中输入分钟数，点击"设定时间"按钮
- **音效控制**：点击"音效"按钮可以开关滴答声和完成音效

### 模式说明

- **专注模式**：默认 25 分钟，紫色渐变背景
- **休息模式**：默认 5 分钟，绿色渐变背景

## 项目结构

```
tomato_clock/
├── main.js           # Electron 主进程文件
├── renderer.js       # 渲染进程逻辑
├── index.html        # 主 HTML 文件
├── style.css         # 样式表
├── package.json      # 项目配置
└── node_modules/     # 依赖包
```

## 技术栈

- Electron 28.0.0
- 原生 HTML/CSS/JavaScript

## 注意事项

- 应用启动时会自动创建一个无边框窗口
- 建议在安静环境下使用以获得最佳体验
- 滴答声可以通过音效按钮关闭

## 开发

如果你需要修改代码：

1. 修改 `renderer.js` 更新计时器逻辑
2. 修改 `style.css` 调整界面样式
3. 修改 `index.html` 更新页面结构
4. 修改 `main.js` 调整窗口配置

运行 `npm start` 即可查看更改效果。
