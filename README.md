# 专业番茄时钟

一个基于 Electron 构建的现代番茄时钟应用，帮助你高效管理时间。

## 功能特性

- ✨ 简洁美观的毛玻璃设计
- ⏱️ 可自定义的专注和休息时间
- 🔔 滴答声和完成音效提醒
- 🎨 平滑的背景过渡效果
- 📱 响应式设计，支持不同屏幕尺寸
- ⏯️ 完整的播放/暂停/重置控制
- 📦 可打包为独立应用，方便分发
- 📢 支持系统级计时通知
- 🌙 暗黑主题支持（可手动切换或跟随系统）
- 🎯 更好的用户体验和界面交互

## 使用说明

### 基本操作

1. **开始专注**：点击"开始"按钮开始计时
2. **暂停计时**：点击"暂停"按钮暂停当前计时
3. **重置计时**：点击"重置"按钮重新开始
4. **切换模式**：点击底部的"休息一下"或"回到专注"按钮在专注和休息模式间切换

### 自定义设置

- **设定时间**：在侧边栏输入框中输入分钟数，点击"设定时间"按钮
- **音效控制**：点击"音效"按钮可以开关滴答声和完成音效
- **主题切换**：点击右上角的月亮/太阳图标手动切换亮色/暗黑主题

### 模式说明

- **专注模式**：默认 25 分钟，紫色渐变背景
- **休息模式**：默认 5 分钟，绿色渐变背景
